\section{Conclusiones}
% ============================================================

El presente trabajo evaluó cinco estructuras de modelo subrogado (ARX, ARMAX, FOPDT, TF y SS) como predictores internos de un esquema MPC aplicado a un proceso de destilación extractiva, tomando como referencia de comparación el modelo de espacio de estados. Lo que evidencia que un proceso riguroso de identificación y entrenamiento es determinante para el desempeño del controlador, independientemente de la estructura de modelo seleccionado.

\vspace{0.25cm}

Es importante mencionar entonces que las métricas de ajuste en lazo abierto, RECM y R², no son un criterio relevante para la selección del modelo en aplicaciones de control predictivo. Lo que determina el desempeño del MPC es la capacidad del modelo para reproducir fielmente los movimientos de la variable controlada dentro del horizonte de predicción, bajo retroalimentación continua y en presencia de perturbaciones. La evaluación mediante criterios integrales de desempeño y costos computacionales mostró mejoras leves frente al espacio de estados en términos dinámicos, aunque más significativas en eficiencia computacional, lo cual es consistente con la menor dimensión estructural de los modelos identificados. Con base en estos resultados, el modelo ARMAX presentó el mejor desempeño para la columna T-101, mientras que el modelo FOPDT fue superior para la columna T-102.
Estos resultados abren la posibilidad de un esquema de control híbrido descentralizado en el que cada controlador emplea el modelo subrogado de mejor desempeño para su subsistema. Como extensiones naturales de este trabajo se identifican dos líneas de investigación: la implementación de un MPC centralizado para el sistema completo, que aproveche explícitamente el acoplamiento dinámico entre ambas columnas en lugar de tratarlo como perturbación no medida; y la extensión hacia MPC no lineal, empleando modelos NLARX o Hammerstein-Wiener, para evaluar si la mayor precisión dinámica justifica el costo computacional adicional cuando el proceso opera lejos del punto nominal de diseño.
